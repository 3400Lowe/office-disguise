# Release notes

## 1.0.0 — Unreleased

Initial Chrome Web Store release in preparation.

- Reddit and X inbox layouts with Outlook-inspired and Gmail-inspired themes.
- Reading panes, feed navigation, native social interactions and media controls.
- Resizable message lists and platform-specific enable switches.
- Configurable keyboard shortcuts and original-site controls.
- Custom header/tab text with Office Disguise defaults; optional theme favicons off by default.
- Local settings, offline third-party notices and no developer analytics.

Future themes displayed as Coming Soon are not implemented or included in this release. No release dates are promised.
