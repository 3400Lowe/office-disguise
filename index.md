# Office Disguise

An independent Chrome extension that presents Reddit and X in an email-style inbox and reading pane, with Outlook-inspired and Gmail-inspired themes.

**The initial Chrome Web Store release is being prepared.** The installation link will appear here when it is available. Both initial themes are included at no charge, with no Office Disguise account required. Future themes marked Coming Soon are not available yet.

GitHub issues are public. Use email for private enquiries and remove sensitive details from screenshots.

Office Disguise is a visual reading interface, not an email service or anonymity tool. Reddit and X still control your account and actions. It does not conceal browsing from network administrators or employers.
