# Office Disguise

Official documentation and support for Office Disguise, an independent Chrome extension that presents Reddit and X in an email-style inbox and reading pane.

**Publisher:** 3400lowe, an individual publisher based in the United Kingdom.  
**Support and privacy contact:** [info@quotesbytrades.co.uk](mailto:info@quotesbytrades.co.uk)

## Availability

The initial Chrome Web Store release is being prepared. A verified installation link will be added here when the listing is available. No store approval or release date is claimed.

The initial version includes Outlook-inspired and Gmail-inspired themes at no charge. Other themes shown as Coming Soon are unavailable. No Office Disguise account is required.

## Features

- Read Reddit and X posts in an inbox and reading pane using your existing site session.
- Switch between Outlook-inspired and Gmail-inspired themes.
- Customise the header, browser tab titles, density, media display and keyboard shortcuts.
- Enable each platform independently and return to the original site at any time.
- Keep settings on your device, without developer analytics or a developer-hosted post database.

Social controls still act on the real Reddit or X account. This is a visual reading interface, not an email service, anonymity tool or a way to hide browsing from an employer, network administrator or browser history.
