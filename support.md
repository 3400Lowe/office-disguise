# Help and support

Contact **3400lowe**, United Kingdom: [info@quotesbytrades.co.uk](mailto:info@quotesbytrades.co.uk).

## Getting started

Once the Chrome Web Store listing is available, install Office Disguise from the link in this repository's README. Open Reddit or X in desktop Chrome and sign in on the site's own page if needed. Never send your password or verification codes to support.

Use Chrome's Extensions menu to open Office Disguise settings. Enable the disguise and the platform you want to use. The inbox appears when supported posts are available.

Choose Outlook-inspired or Gmail-inspired under Current theme or Themes. Other themes are marked Coming Soon and cannot be selected.

## Common controls

- Click a post to read it. Up and Down open the previous or next post.
- Escape closes extension menus first, then closes the selected post. It keeps the disguise enabled.
- Show original site, or Alt+Shift+O by default, returns to the native site. Resume inbox view returns to the disguise.
- Appearance controls the header, tab titles and optional theme favicon. Favicon replacement is off by default.
- Display & Media controls density, media collapse and folders. The Gmail-inspired theme also has a reading-pane setting.
- Platforms enables Reddit and X independently.
- Keyboard Shortcuts lets you change, disable or reset in-page bindings. Browser shortcuts are managed separately at `chrome://extensions/shortcuts`.

## If the inbox does not appear

1. Check that both the disguise and the current platform are enabled.
2. Reload the tab after installing or updating the extension.
3. Complete any sign-in, consent or human-verification prompt on the original site yourself.
4. Check whether Advanced's sponsored-content option is returning you to the original page.
5. Some unsupported pages and native dialogs stay on the original site. Reddit and X markup changes can also affect compatibility.

## If a post or interaction looks wrong

Use Show original site to access the native page. Report which platform and theme you used, the extension and Chrome versions, what happened and what you expected. A public page URL or sanitised screenshot can help, but is optional. Do not attach cookies, access tokens, private messages, browser profiles or unsanitised network logs.

## Reporting problems

[Create a GitHub issue](https://github.com/3400Lowe/office-disguise/issues/new/choose) for public bug reports and feature requests. GitHub requires an account to post. Email support if you prefer, or if your report contains private information. There is no guaranteed response time.

## Resetting or removing the extension

Advanced → Restore default settings resets preferences and in-page shortcuts. Chrome-managed shortcuts are separate. Uninstall through `chrome://extensions` to remove extension storage. The small theme preference stored in Reddit/X site storage can remain until you clear that site's data; clearing site data may sign you out.

Office Disguise changes the presentation of supported pages. It does not conceal network activity, change workplace rules or replace the sites' own privacy controls.
