# Security reports

Please report suspected vulnerabilities privately to **info@quotesbytrades.co.uk**, with the subject **Office Disguise security report**.

Include the affected extension version, a description, and safe reproduction steps. Do not send passwords, tokens, cookies, private post contents or other people's data. Do not publish an exploit in a public issue before the publisher has had an opportunity to investigate.

This project does not currently offer a bug bounty or guaranteed response time. General bugs and feature requests belong in GitHub Issues.
